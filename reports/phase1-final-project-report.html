1. Executive Summary

The Metal Inspection Assistant is an edge-native quality control system engineered to satisfy Problem Statement 5 (PS5) of the Bharat AI-SoC Challenge. Operating entirely on an Arm Cortex-A mobile platform without cloud dependence, the system integrates a dual-runtime pipeline: (1) real-time OpenCV surface defect metrology and classification achieving 83.70% accuracy across standardized steel surface defect classes, accompanied by automated non-defective part screening; and (2) on-device advisory reasoning powered by Llama 3.2 1B Instruct on ExecuTorch, translating structured defect records into concrete, actionable Standard Operating Procedures (SOP) for shop-floor operators.

5. Automated Severity Metrology & Non-Defective Screening

5.1 Deterministic Morphological Metrology

Because real-world surface defect datasets lack subjective categorical severity ratings, our edge pipeline computes deterministic mathematical surface density metrology directly on-device in OpenCV:

δ = ( ∑ Area(Contouri) / AROI ) × 100%

  • Pass / Clear for Production: δ < 1.0% (specimen clear of surface flaws; meets tolerance for assembly).
  • Low Severity: 1.0% ≤ δ < 2.5% (isolated inclusions, shallow pitting; monitor trend).
  • Medium Severity: 2.5% ≤ δ < 8.0% (moderate scratches, localized scale; secondary supervisor check).
  • High Severity: δ ≥ 8.0% (extensive crazing, heavy scale; immediate quarantine Red Tag).

5.2 Clean Specimen Handling & Quality Disposition Bar

To ensure clean metal components are not falsely classified as defective, OpenCV inspects boundary corner pixel luminance (>235). Clean specimens on neutral backgrounds are automatically screened with 0.0% defect density. Furthermore, a prominent 1-tap Quality Disposition Action Bar allows operators to confirm findings or instantly apply [PASS / NO DEFECT], updating the header to Neon Emerald Green (STATUS: PASS · Clear for Production) and releasing the lot with Green Tag clearance.

6. Llama 3.2 1B on ExecuTorch: Advisory Reasoning Copilot

The challenge-mandated Llama 3.2 1B Instruct model is deployed locally using the reference ExecuTorch runtime on Arm Cortex-A. To guarantee reliable on-device execution without freezing or truncation:

  • Token Budget Optimization: The prompt is compacted to ~55 tokens within a 128-token sequence limit, leaving 73 tokens headroom for generation.
  • Concrete Shop-Floor Guidance: Llama receives domain SOP cues for every defect class, generating actionable instructions (e.g., checking descaling nozzle pressure, roll cooling sprays, or buffer polishing) rather than generic textbook theory.
Verified On-Device Output (Clean Specimen):
“The operator should: 1. Affix the Green Tag to the component. 2. Release the component to production assembly. 3. Log batch clearance. This is the standard action for completing a Clean / No defect lot.”
